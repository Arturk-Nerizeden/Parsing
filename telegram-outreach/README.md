# Telegram Outreach

Отдельное расширение Chrome (Manifest V3) для сообщений готовому списку **Telegram** `@username` от вашего личного аккаунта. Это самостоятельный проект: расширение Web3 Audience Explorer и его данные не используются. Никнейм из X сам по себе не считается контактом Telegram.

Расширение импортирует список, убирает дубли, подставляет имя из CSV, показывает текст для выбранного получателя и при желании добавляет одну картинку ко всей очереди. Текст отправляется как подпись к картинке одним сообщением. Для каждого получателя сохраняются статус, время, подтверждённый Telegram ID сообщения или причина ошибки. Есть теги, фильтр, CSV-журнал и общий список «не писать».

## Установка готовой сборки

1. Скачайте `release/telegram-outreach-v1.0.0.zip` и распакуйте его в отдельную папку. Не выбирайте ZIP как папку расширения.
2. В Chrome откройте `chrome://extensions`, включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное** (**Load unpacked**) и выберите папку, куда распакован ZIP. В ней должен лежать `manifest.json`.
4. Нажмите иконку расширения, чтобы открыть страницу Telegram Outreach.

Для сборки из исходников требуется Node.js 20 или новее:

```sh
npm ci
npm run build
```

Затем загрузите папку `dist` через **Load unpacked**. Для нового ZIP выполните `npm run package`.

## Как пользоваться

1. Получите **API ID** и **API hash** для вашего Telegram-приложения на [my.telegram.org/apps](https://my.telegram.org/apps). Это два разных значения; они не имеют отношения к ключу Sorsa или токену бота. В расширении нажмите **Подключить Telegram**, введите ID, hash, телефон, затем код входа и, если потребуется, пароль двухэтапной проверки. Не передавайте эти данные другим людям.
2. Вставьте готовые Telegram `@username` или `t.me/username` по одному на строку. Можно импортировать TXT или CSV размером до 1 МБ. В CSV нужен один столбец `username`, `telegram` или `telegram_username`. Дополнительные столбцы `first_name` (либо `display_name` или `name`) и `tags` необязательны. Пример:

   ```csv
   username,first_name,tags
   @alice,Алиса,"партнёры, конференция"
   @bob,,партнёры
   ```

3. Напишите сообщение; доступны `{{first_name}}` и `{{username}}`. Если имени нет, вместо него подставится `@username`. Проверьте результат в **Предпросмотре** для разных получателей. Общие теги можно ввести отдельно.
4. При желании нажмите **Добавить картинку**. Поддерживаются JPEG и PNG до 5 МБ; подпись после подстановки ограничена 1024 символами. Без картинки текст ограничен 4096 символами. Картинка сохраняется локально вместе с очередью и доступна после перезагрузки страницы.
5. Создайте очередь, выберите интервал, проверьте аккаунт и список в окне подтверждения, затем нажмите **Отправить**. Вкладка должна оставаться открытой. Кнопка **Пауза** останавливает очередь после текущего запроса. После перезапуска браузера очередь остаётся в локальном хранилище, но для продолжения может потребоваться повторный вход.
6. При неопределённом результате строка получает статус **Проверить**. Откройте диалог в Telegram и отметьте уже отправленное сообщение вручную; приложение не повторяет такую отправку автоматически. Ошибки и очередь можно выгрузить через **Экспорт CSV** (UTF-8 с BOM).

Бот Telegram не может первым писать любому `@username`. Поэтому расширение использует официальный клиентский Telegram API (MTProto) под вашим личным аккаунтом. Оно не обходит лимиты Telegram: при `FLOOD_WAIT` сохраняет срок паузы и не позволяет продолжить раньше. Ограничения и настройки приватности получателей могут помешать доставке. Применяйте расширение только к контактам, которым уместно писать; массовая нежелательная рассылка может привести к ограничениям аккаунта.

## Данные и безопасность

Расширение общается напрямую с дата-центрами Telegram через `*.web.telegram.org`. Оно не читает Telegram Web, не забирает cookies и не отправляет данные на сторонний сервер. API hash и сессия хранятся в `chrome.storage.session` только для доверенных страниц расширения и удаляются при закрытии браузера; очереди, журнал и стоп-лист хранятся в `chrome.storage.local`, а картинки — в IndexedDB этого расширения. Фото и подпись отправляются только указанным адресатам через Telegram API. Если компьютер общий, защищайте профиль Chrome и выходите из аккаунта после работы.

Приложение отправляет сообщения лишь при открытой вкладке и явном запуске очереди. Оно не отправляет сообщения в фоне после закрытия вкладки. Старые очереди сохраняются локально, пока вы их не удалите или не очистите данные расширения.

## Проверка проекта

```sh
npm test             # модульные тесты импорта, шаблонов, очереди, картинки и экспорта
npm run test:browser # сборка и сценарий в Chromium без отправки сообщений
npm run build        # проверка TypeScript, сборка и проверка MV3/CSP/локальных WASM
npm run package      # сборка ZIP для установки
```

Автоматические проверки не используют Telegram-аккаунт и не подтверждают успешный вход или доставку в реальную сеть. Первый реальный запуск нужно проверить на собственном тестовом адресате.
