# Telegram · Username Collector

Отдельное расширение для отправки сообщений готовому списку Telegram-контактов, включая картинку с подписью: [Telegram Outreach](telegram-outreach/README.md). Оно устанавливается отдельно и не использует данные этого сборщика автоматически.

Расширение для Chrome / Edge / Chromium 120+: собирает публичные username авторов сообщений из **открытого чата или открытой ветки комментариев в Telegram Web K**. Дополнительно находит `@упоминания` и ссылки `t.me` в тексте сообщений. Результаты сохраняются в браузере и экспортируются в CSV, TXT и JSON.

## Установка

1. Скачайте и распакуйте `downloads/telegram-username-collector-v1.0.0.zip` либо используйте папку `extension` из этого репозитория.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`). Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите папку, в которой лежит `manifest.json`.
4. Откройте **https://web.telegram.org/k/** и войдите в свой аккаунт обычным способом. Если Telegram уже открыт, обновите его вкладку после установки расширения.
5. Закрепите расширение на панели браузера для удобного доступа.

## Как собрать username

1. Откройте нужный чат. Для комментариев перейдите в канал и нажмите **Комментарии** под конкретным постом — сбор работает с открытой веткой.
2. Перейдите к позиции, с которой нужно начать сбор. Расширение читает загруженные сообщения и, при включённой автопрокрутке, движется в выбранном направлении.
3. Нажмите значок расширения. Оставьте **Авторы сообщений**, при необходимости включите **Упоминания и ссылки**.
4. Выберите направление и лимит сообщений. Для сбора только уже загруженных сообщений выключите автопрокрутку.
5. Нажмите **Начать сбор**. Можно закрыть окно расширения; вкладка Telegram должна оставаться открытой. **Стоп** завершает сбор с сохранением результата.
6. Выберите источник или введите поисковый фильтр. **Копировать**, CSV, TXT и JSON выгружают все строки по текущему фильтру, даже если в окне показаны только первые 100.

Новый сбор заменяет предыдущий результат **этой вкладки**. Для объединения нескольких чатов экспортируйте каждый отдельно. При смене чата, ветки, URL или аккаунта активный сбор останавливается. После перезагрузки вкладки доступны сохранённые результаты; автоматическое продолжение не выполняется.

## Возможности и границы

| Сценарий | Web K | Web A |
|---|---|---|
| Username авторов сообщений / комментариев | Да, из загруженных данных клиента | Нет: используйте Web K |
| Упоминания и публичные ссылки в тексте | Да | Да |
| Автопрокрутка открытой истории | Да | Да |
| Пользователи без публичного username | Отдельный счётчик | Не определяются |
| Экспорт CSV / TXT / JSON, удаление дублей | Да | Да |

- В список авторов попадает **автор текущего сообщения**, а не исходный автор пересланного сообщения. Боты-авторы включаются отдельной настройкой; сообщения от имени каналов не считаются пользователями. Полнота счётчика зависит от доступности данных автора.
- Упоминание или ссылка не подтверждает участие в чате: это может быть пользователь, бот или канал. Эти источники отмечены отдельно; фильтр ботов применяется только к подтверждённым авторам.
- Учитываются активные дополнительные username одного пользователя. Число username поэтому может превышать число авторов. Дубли удаляются без учёта регистра.
- Расширение не получает весь список участников и не открывает автоматически комментарии ко всем постам канала. Оно обрабатывает только сообщения открытой переписки, которые загрузил Telegram.
- Лимит — до 10 000 сообщений и до 10 000 уникальных username за запуск. Прокрутка начинается с текущей позиции и останавливается после нескольких циклов без новых сообщений и движения. Это не подтверждает сбор всей истории. Медленная сеть или изменения Telegram могут потребовать повторного запуска.
- Если Telegram ещё не загрузил данные автора, сообщение учитывается как **автор не прочитан**, а не как пользователь без username. При следующем цикле оно проверяется снова, пока находится в загруженной области.
- Сбор авторов использует внутренний интерфейс `apiManagerProxy` Web K. Он не является стабильным публичным API. Если он недоступен, расширение показывает ошибку; режим упоминаний остаётся независимым от него.
- Текущая проверка выполнена в Chromium на воспроизводимых тестовых страницах с разметкой и формой данных, сверенными с исходниками Telegram. Работа в вашем авторизованном аккаунте и конкретной текущей сборке Telegram ещё требует проверки. Исследование и ссылки — [docs/RESEARCH.md](docs/RESEARCH.md).

## Данные и разрешения

Обработка выполняется локально. У расширения нет своего сервера, аналитики или прямых запросов к Telegram API. API ID, API hash и токен бота не нужны. Оно не читает ключи сессий, телефонные номера и биографии; из кеша выбираются только авторы сообщений, присутствующих в DOM. Автопрокрутка вызывает обычную загрузку истории самим Telegram.

Разрешения: `activeTab` для связи с выбранной вкладкой, `storage` для локальных результатов, `clipboardWrite` для копирования. Скрипты запускаются только на `https://web.telegram.org/*`. Максимум восемь последних вкладок сохраняются в локальном хранилище расширения. **Очистить** удаляет текущий результат. Удаление расширения удаляет его локальное хранилище; уже экспортированные файлы остаются у вас.

CSV содержит UTF-8 BOM для Excel и защиту строк от выполнения формул. В JSON и CSV сохраняются username, ссылка, источники (`author`, `mention`, `link`), ID подтверждённого автора, название чата, число находок и до 20 ID сообщений для каждой строки. Одна находка — сочетание username, источника и сообщения; повторная обработка того же сообщения счётчик не увеличивает. TXT содержит по одному `@username` на строку.

## Разработка

Node.js 20+ и Python 3 для упаковки. Для самого расширения сборка и npm не нужны.

```bash
cd /workspace/Parsing
npm ci --ignore-scripts --cache /tmp/parsing-npm-cache
npm test
npm run check
npm run test:browser
npm run package
```

Браузерные проверки используют установленный Chromium (`/usr/bin/chromium`). Для другого пути задайте `CHROMIUM_PATH=/путь/к/chromium npm run test:browser`. Для них не нужен аккаунт Telegram и не выполняются запросы к реальным чатам. Снимок окна расширения после проверки: `test-results/popup.png`.

`test:browser` исполняет реальные файлы content script в изолированном мире браузера, bridge — в мире страницы, background — в VM; функции Chrome API для обмена сообщениями и хранения заменены тестовыми реализациями. Проверка установки настоящего расширения: **`npm run test:extension`**. В текущей облачной среде она заблокирована политикой администратора Chromium `ExtensionInstallBlocklist: ["*"]`; установка Manifest V3 и работа с настоящими Chrome API здесь не подтверждены. Запустите этот тест в Chromium, где разрешены расширения, либо выполните шаги установки выше.

Структура: `core.js` — разбор и экспорт, `adapters.js` — область сообщений Web K / A, `bridge.js` — ограниченное чтение кеша Web K, `content.js` — цикл сбора, `background.js` — хранение по вкладкам, `popup.*` — интерфейс. Зависимость Playwright нужна только для разработки и не входит в архив расширения.
